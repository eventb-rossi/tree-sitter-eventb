; Identifiers use Rodin's alphabet: Java's identifier classes over Unicode,
; minus the lambda letter and the dollar sign (grammar.js `IDENT_START`).
; The letter glyphs ℕ, ℤ and ℙ are identifier characters too, so `ℤx` is one
; identifier while the bare glyph stays the keyword, as in Rodin's lexer.

================================================================================
identifiers: Unicode letters and a glyph-prefixed name
================================================================================

context C
  constants α ℝ ℤx ℕ1x naïve
  axioms
    @a α ∈ ℤ
    @b ℤx ⊆ ℙ(ℝ)
end
